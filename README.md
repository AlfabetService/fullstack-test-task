# Тестовое задание: FullStack-разработчик

## Задача

В папке [`data/`](./data/README.md) лежат 100 рецептов и каталог продуктов (foods), которые в них
используются. У рецепта есть число порций и список ингредиентов, у каждого
ингредиента — количество, единица измерения и ссылка на продукт из каталога. Нутриентов в этих
данных нет.

Нужно сделать веб-приложение, которое показывает пищевую ценность каждого рецепта.

Источник нутриентов — открытая база [USDA FoodData Central](https://fdc.nal.usda.gov/). Как её
получить и в каком виде использовать, решаете вы.

Что должно работать:

1. **Список рецептов.**
2. **Страница рецепта** с КБЖУ (калории, белки, жиры, углеводы) на весь рецепт и на одну порцию,
   с разбивкой по ингредиентам.
3. **Привязка продуктов к USDA.** Экран, где видно, какой продукт из каталога к какой записи USDA
   привязан, какие продукты ещё не привязаны, и где привязку можно задать или изменить через
   поиск по USDA. Как именно вы получите первоначальные привязки — руками, скриптом, с помощью
   AI или как-то ещё — ваше решение.
4. Если у рецепта есть продукт без привязки, страница рецепта честно показывает, что данные
   неполные.

Задание намеренно не описывает всё. Там, где требования неполны, принимайте решение сами и
запишите его в README своего проекта.

## Ограничения

- TypeScript и Node.js обязательны. Остальной стек — фреймворки, база данных, способ хранения — на ваш выбор.
- Авторизация и деплой не нужны. UI не главное: достаточно, чтобы им можно было пользоваться, на
  отделку время не тратьте.
